# Bulls and Cows Game – Engeto Python Academy Project 2

This is the second project submitted for the **Engeto Online Python Academy**. It’s a simple console-based implementation of the classic guessing game **Bulls and Cows**.

## 🎮 Game Description

- The program generates a **random 4-digit number**.
- All digits are **unique**, and the number **does not start with zero**.
- The player attempts to guess the number.
- After each guess, the program provides feedback in the form of:
  - **Bulls**: correct digit in the correct position
  - **Cows**: correct digit in the wrong position
- The game ends when the number is correctly guessed or the player types `cancel`.
- At the end, the number of guesses and total time spent are displayed.

## ✅ Input Validation

The input must:
- Be a **4-digit number**
- **Not start with 0**
- Contain **only digits**
- Have **no repeating digits**
